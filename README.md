# Git Lab 1 – Overview

This lab covers basic and advanced Git operations using a local Git repository and GitHub.

The main objective is to understand repository initialization, file tracking, staging, committing, pushing, pulling, branching, merging, and collaboration through pull requests.

### Topics Covered

1. **Git Repository Initialization:** Creating a local repository, adding files, and making the initial commit on the main branch.

2. **Remote Repository Operations:** Connecting the local repository to GitHub, pushing commits, pulling remote changes, and managing staged and unstaged files.

3. **Branching and Pull Requests:** Creating and switching branches, making changes, pushing them to GitHub, and creating and merging pull requests.

4. **Local Git Operations:** Practicing `git fetch`, `git merge`, `git reset`, `git diff`, `git ls-files`, and `git add -p` to manage changes and track files.

5. **Branch Merging and Conflict Resolution:** Creating multiple branches, merging them in sequence, resolving merge conflicts, and deleting local and remote branches.

6. **Fork Operations:** Forking a repository, cloning the fork, making changes, pushing them, and creating a pull request to the original repository.

7. **Repository Status and Change Management:** Using `git status`, `git diff`, `git rm`, and `git revert` to inspect repository changes and manage files.

### Conclusion

This lab provides practical experience with Git and GitHub, including version control, branch management, change tracking, conflict resolution, and pull request workflows.
